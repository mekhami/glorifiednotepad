Introduce the characters using short, few paragraph flash fiction instead of description. Use four different styles of writing:

1. Third person, start with description
2. Third person, start in the middle of dialogue
3. First person
4. Start with internal thoughts? Or maybe start as some editorial, news article, some academic writing focused on the character as if in retrospect? or a report like on the news, or a report like a police report, a document on that character
